6-Axis AHRS

强大的六轴姿态航向参考系统 (AHRS) 实现

Madgwick EKF ESP32 STM32

项目简介

一个稳健的独立六轴（陀螺仪 + 加速度计）姿态和航向参考系统 (AHRS) 实现。该库提供了两种算法：基于 Madgwick 的原始融合算法和适用于复杂环境的高级扩展卡尔曼滤波器 (EKF)。

核心特性

Madgwick 融合算法

基于 Sebastian Madgwick 博士论文第七章的实现，稳定可靠。

扩展卡尔曼滤波 (EKF)

6状态 EKF，估计姿态四元数和陀螺仪偏置，自适应滤波。

冲击检测与恢复

检测高加速度事件，快速恢复姿态估计。

线性运动补偿

检测并补偿线性加速度干扰，提高精度。

自动陀螺仪偏置校正

实时估计并补偿陀螺仪零漂。

自适应权重

根据四元数相似度动态调整融合权重。

硬件支持

  • 嵌入式系统：STM32, ESP32
  • 6轴 IMU（陀螺仪 + 加速度计）

快速使用

Madgwick 版本

#include "Fusion_AHRS.h" FusionAhrs ahrs; FusionOffset offset; FusionAhrsInitialise(&ahrs); FusionOffsetInitialise(&offset, 100); // 100 Hz FusionVector gyro = {gx, gy, gz}; // deg/s FusionVector acc = {ax, ay, az}; // g gyro = FusionOffsetUpdate(&offset, gyro); FusionAhrsUpdate(&ahrs, gyro, acc, 0.01f); FusionQuaternion q = FusionAhrsGetQuaternion(&ahrs); FusionEuler euler = FusionQuaternionToEuler(q);

EKF 版本

#include "Tactical_Fusion.h" TacticalSystem sys; Tactical_Init(&sys, 100.0f, 0.1f); // 100 Hz, 0.1 Hz 波浪频率 FusionVector gyro = {gx, gy, gz}; // deg/s FusionVector acc = {ax, ay, az}; // g Tactical_Update(&sys, gyro, acc); FusionQuaternion q = sys.quaternion;
